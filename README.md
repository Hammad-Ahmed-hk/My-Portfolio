# Hammad Ahmed: Portfolio Website

My personal portfolio site: a single-page site about me, my skills and my projects in AI, machine learning and software engineering.

**Live site:** https://hammad-ahmed-hk.github.io/My-Portfolio/

## Sections

- **Hero:** introduction and links to GitHub, LinkedIn and Twitter
- **About:** background and interests
- **Technical skills:** languages, ML and data science, frameworks and tools
- **Journey:** timeline of my path so far
- **Featured projects:** project cards with short descriptions
- **Contact:** social links

## Tech stack

HTML5, Tailwind CSS (CDN), JavaScript, [AOS](https://michalsnik.github.io/aos/) scroll animations, Font Awesome icons.

## Run locally

No build step is needed. Clone the repo and open `index.html`, or serve it:

```bash
git clone https://github.com/Hammad-Ahmed-hk/My-Portfolio.git
cd My-Portfolio
python -m http.server 8000   # then visit http://localhost:8000
```
